# Responsive Navigation Bar

## 📌 Project Description
This project demonstrates a simple navigation bar created using HTML5 and CSS3. It includes a logo, navigation links, and a login button with basic hover effects.

## 🚀 Features
- Navigation bar using CSS Flexbox
- Logo section
- Home, About, and Contact navigation links
- Login button
- Hover effects on buttons and navigation links
- Custom colors, borders, and spacing

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox
